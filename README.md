# SikaPOS / Akoma Commerce Cloud

> Multi-tenant SaaS Cloud POS & Inventory System tailored for Ghanaian & West African SMB Retailers.

## Overview

SikaPOS (*Sika* = Gold / Money in Akan) is an offline-resilient, multi-tenant cloud point-of-sale and retail management platform designed for speed, clarity, and ease of use across mobile and desktop devices.

## Repository Contents

- **`sikapos_design_system/`**: Design tokens, color system, and UI foundations.
- **`sikapos_design_system_specification_stage_1_lock.txt`**: Complete Stage 1 design specifications, tokens, and components lock.
- **`sikapos_akoma_logo/`**: Brand logo assets and visual marks.
- **`merchant_signup_welcome/`**: Merchant onboarding and registration interface.
- **`business_store_setup_wizard/`**: Multi-step business profile, store configuration, and currency/tax setup wizard.
- **`cashier_pin_launch_readiness/`**: Terminal readiness checklist and launch screen.
- **`cashier_pin_login_otp_verification/`**: Rapid PIN pad authentication and phone OTP verification flow.
